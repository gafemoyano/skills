# Personal agent kit

Curated cross-agent skills for gafemoyano. See README.md for installation.

- Add new skills under skills/<name>/SKILL.md; directory and frontmatter names must match.
- always-on.json is the single list of skills embedded into personal instruction files.
- After adding or editing skills, run python3 -m unittest discover -s tests and python3 scripts/install.py.
- Never replace unrelated installed skills or personal instructions.
- Keep this repository private until copied material's attribution and licensing are checked.
